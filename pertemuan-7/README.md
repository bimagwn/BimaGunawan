## Isi proyek akhir per pertemuan

| # | Materi | Hasil di proyek |
|:-:|---|---|
| 1 | Rancangan aplikasi ERP | rancangan dan dokumentasi aplikasi (di [LA/](LA)) |
| 2 | OOP Java | paket `id.ramenku.oop`: Encapsulation, Inheritance, Polymorphism |
| 3 | MVC Java: login dan JDBC | login, Menu dan Resep, Stok Bahan, Penjualan, koneksi MySQL |
| 4 | ORM Java | entitas Hibernate di paket `id.ramenku.data` |
| 5 | Spring Java | Spring mengelola Hibernate lewat DAO, transaksi, dan AOP (paket `id.ramenku.spring`) |
| 6 | JasperReports | laporan stok bahan dan struk dalam PDF, Word, dan Excel |
| 7 | GitHub dan Review | proyek dan database diunggah ke GitHub |

Kelas `Galat.java` (JDBC, Pertemuan 3) dan `HibernateUtil.java` (Pertemuan 4) tidak ada di proyek akhir karena perannya sudah digantikan Spring sejak Pertemuan 5. Keduanya tetap tersimpan di folder `kode` Pertemuan 3 dan 4.
