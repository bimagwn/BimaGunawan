# Kode Pertemuan 3: login dan JDBC

Versi RamenKu pada Pertemuan 3 (MVC Java dan JDBC). Akses data memakai **JDBC langsung** (`PreparedStatement` dan `ResultSet`).

- Halaman login (`LoginForm`) dan menu utama.
- Tiga fitur: Menu dan Resep, Stok Bahan, Penjualan.
- Laporan PDF dengan JasperReports (laporan stok dan struk).
- Database MySQL `ramenku_db`: skema dan data contoh ada di `database/ramenku_db.sql`.

## Menjalankan
1. Nyalakan MySQL di XAMPP dan impor `database/ramenku_db.sql`.
2. Klik ganda `bangun.bat`, lalu `jalankan.bat`.

Versi terbaru proyek (Hibernate) ada di folder `pertemuan-4/kode` dan di akar repo.
