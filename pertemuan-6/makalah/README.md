# Makalah Pertemuan 6: JasperReports

Makalah praktikum Rekayasa Perangkat Lunak 2 pengganti LA 6, disusun dengan template makalah laboratorium: teori dan bentuk umum program, contoh program beserta tampilan dan logikanya, serta soal dan jawaban TP dan LP. Listing dipisah per berkas (pom.xml, Laporan.java, PanelStokBahan.java, stok_bahan.jrxml, struk.jrxml), dan logikanya dijelaskan per potongan listing seperti format LA. Halaman isi memakai margin format LA: atas 4, bawah 3, kiri 4, kanan 3 cm.
