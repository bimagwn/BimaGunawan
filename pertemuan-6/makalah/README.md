# Makalah Pertemuan 6: JasperReports

Listing berisi pom.xml, project NetBeans (Java), dan desain laporan (.jrxml). Logika kode dirangkum dalam tabel isi dan kegunaan tiap listing. Halaman isi memakai margin format LA: atas 4, bawah 3, kiri 4, kanan 3 cm.
